# Chinese-Learning-App-QA-Testing
## Project Overview
This project demonstrates the manual testing performed on a Chinese language-learning mobile application. The application provides features such as user registration, AI Chat, AI Talk, Stories, language-learning activities, premium plans, and progress tracking.
The objective of testing was to verify the functionality, usability, validations, and overall user experience of the application.
## Module Tested
- Sign Up and Login
- Email OTP Verification
- Home Dashboard
- AI Chat
- AI Talk
- Stories
- Learning Progress Tracker
- Premium Subscription
- Advertisement and Reward Features
